# Aman Kumar Portfolio

A personal portfolio website for **Aman Kumar**, an MCA student and full-stack developer. It presents projects, technical skills, certifications, contact options, feedback, and a downloadable resume.

## Live Website

After GitHub Pages is enabled, the site will be available at:

`https://aman-kumar990.github.io/portfolio/`

## Features

- Responsive modern portfolio design
- Profile introduction and skills overview
- Project and certificate links
- Resume PDF download
- LinkedIn, GitHub, email, phone, and WhatsApp contact links
- Rating and feedback form
- Portfolio chatbot with microphone input in supported browsers

## Built With

- HTML5
- CSS3
- JavaScript

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. For the best experience, run it with a local server such as VS Code Live Server.

## Deploy to GitHub Pages

1. Push this project to a GitHub repository named `portfolio`.
2. Open the repository on GitHub.
3. Go to **Settings** > **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`.
6. Click **Save**.

Each push to the `main` branch automatically updates the live website.

## Updating Projects

The project cards are currently managed in `index.html`. To add a new project, add its title, description, technologies, and GitHub link to the Projects section, then commit and push the changes.
